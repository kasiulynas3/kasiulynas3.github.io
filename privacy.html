Privacy policy: VelvetMoose47 Uploader

Last updated: 25 October 2026

VelvetMoose47 Uploader is a private tool used only by the owner of the VelvetMoose47 YouTube channel to upload that channel's own videos. It is not offered to the public.

What data it uses

Through Google's OAuth sign-in, the tool gets permission to upload videos to the owner's YouTube channel (youtube.upload) and to read basic information about that channel, such as its ID and name, to confirm it uploads to the right channel (youtube.readonly).

How the data is stored

The sign-in token is stored only on the channel owner's own computer. It is never sent to any server other than Google's, and never shared, sold or used for advertising.

Google API Services

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses YouTube API Services and follows the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions: open an issue on this site's GitHub repository, or use the contact email on the VelvetMoose47 YouTube channel.
