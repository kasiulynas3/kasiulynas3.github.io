Privacy policy: VelvetMoose47 Uploader

Last updated: 26 October 2026

VelvetMoose47 Uploader is a private tool used only by the owner of the VelvetMoose47 YouTube channel to upload that channel's own videos. It is not offered to the public.

YouTube API Services

VelvetMoose47 Uploader uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's use of data is described in the Google Privacy Policy.

What data it accesses and why

Through Google's OAuth sign-in, the channel owner gives the tool two permissions:

  • youtube.upload: to upload the channel's own videos and set their thumbnails.
  • youtube.readonly: to read the channel's ID and name, so it never uploads to the wrong channel, and to check that each uploaded video finished processing.

It does not read comments, subscribers, analytics, other users' data or any other channel's data.

What it stores

  • The OAuth sign-in token, stored only on the channel owner's own computer.
  • A small upload receipt for each of the channel's own uploads (video ID, title, link, scheduled release time), stored on the same computer so the same file is never uploaded twice.

The tool has no servers and no database. It uses no cookies, trackers or analytics, and stores nothing on any other device.

How data is shared

Data is sent only to Google's YouTube API. It is never shared with, sold to or disclosed to anyone else, and never used for advertising.

Revoking access and deleting data

Access can be revoked at any time on the Google security settings page: security.google.com/settings/security/permissions. Revoking stops all access straight away.

To delete the stored data, the owner deletes the token file and the upload receipts from their computer. Nothing is kept anywhere else.

Google API Services User Data Policy

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions: use the contact email on the VelvetMoose47 YouTube channel, or open an issue on this site's GitHub repository.
